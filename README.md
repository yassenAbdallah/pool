# مساحتي — الدفتر والبيانات

موقع بسيط: تدخل بكلمة سر، وكل كلمة سر بتفتح حاجة مختلفة. البيانات بتتحفظ في **ملف JSON** على جهازك.

**اللينك المباشر:** https://yassenabdallah.github.io/pool/

## كلمات السر

| كلمة السر | بتروح فين |
|-----------|-----------|
| `123` | الدفتر: تكتب وتعدل وتحذف السجلات |
| `321` | البيانات: تعرض كل اللي سجلته + إحصائيات + بحث وفلترة + تصدير CSV/JSON |

> صفحة البيانات للعرض فقط — عشان تضيف أو تعدل، ادخل بوضع الدفتر (123).

## طريقة التشغيل

- افتح اللينك المباشر فوق، أو دبل كليك على `index.html` في أي متصفح حديث.
- مش محتاج تسطّب أي حاجة.

## الحفظ في ملف JSON

الموقع بيستخدم **File System Access API** (مدعومة في Chrome وEdge على الكمبيوتر):

1. أول ما تدخل، هيسألك تختار ملف البيانات:
   - **إنشاء ملف جديد** → هتختار مكان واسم الملف (مثلاً `masahy-data.json`).
   - **فتح ملف موجود** → لو عندك ملف بيانات قديم.
2. بعد كده أي إضافة أو تعديل أو حذف بتتحفظ في الملف **تلقائيًا**.
3. شكل الملف:

   ```json
   {
     "app": "masahy",
     "version": 1,
     "updatedAt": "2026-11-06T13:33:56.115Z",
     "records": [
       {
         "id": "...",
         "title": "فاتورة الكهرباء",
         "category": "مصاري",
         "content": "مبلغ 350 جنيه",
         "createdAt": 1793972056935,
         "updatedAt": 1793972056935
       }
     ]
   }
   ```

4. لو قفلت الصفحة وفتحتها تاني، المتصفح ممكن يطلب إذن الكتابة مرة كمان — اضغط **«إعادة ربط الملف»** أو من الزرار اللي فوق (اسم الملف).
5. **نسخة محلية تلقائية:** السجلات بتتحفظ كمان نسخة على الجهاز، فبتظهر فورًا أول ما تفتح الصفحة حتى قبل إذن الملف، وده بيخليك تشتغل من غير نت. أي إضافة أو تعديل وانت مش متصل بتتحفظ في النسخة المحلية، وأول ما تدوس «إعادة ربط الملف» بتتكتب في ملف الـ JSON.
6. لو نقلت الملف أو مسحته، اربط ملف تاني من نفس الزرار.
7. **ترحيل تلقائي:** أي بيانات قديمة كانت محفوظة في المتصفح بتتنقل للملف أول مرة تربط فيها، والنسخة القديمة بتتمسح.

### ملاحظات

- الملف على **جهازك فقط** ومش مرفوع على GitHub.
- لو نسخت الملف، تقدر تفتحه من أي جهاز عليه Chrome/Edge عن طريق «فتح ملف موجود».
- في صفحة البيانات زرار **«تحديث من الملف»** لو عدّلت الملف من برة.
- المتصفحات اللي مش بتدعم الكتابة في الملفات (زي Firefox أو موبايل): فيها خيار **«استخدام حفظ المتصفح»** مع تصدير CSV/JSON كنسخة احتياطية.
- **قيد المتصفح:** مفيش أي موقع على الويب يقدر يكتب في ملف من غير موافقتك. Chrome بيفتكر الملف ويعرضه تلقائي، لكن الكتابة بتحتاج ضغطة واحدة على «إعادة ربط الملف» في أول فتحة لكل جلسة متصفح. الحفظ نفسه بيشتغل من غير نت.
