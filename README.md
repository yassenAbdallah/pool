# مساحتي — الدفتر والبيانات

موقع بسيط من غير سيرفر: تدخل بكلمة سر، وكل كلمة سر بتفتح حاجة مختلفة.

## كلمات السر

| كلمة السر | بتروح فين |
|-----------|-----------|
| `123` | الدفتر: تكتب وتعدل وتحذف السجلات |
| `321` | البيانات: تعرض كل اللي سجلته + إحصائيات + بحث وفلترة + تصدير CSV/JSON |

> صفحة البيانات للعرض فقط — عشان تضيف أو تعدل، ادخل بوضع الدفتر (123).

## طريقة التشغيل

- افتح `index.html` بدبل كليك في أي متصفح حديث (Chrome / Edge / Firefox).
- مش محتاج إنترنت ولا تثبيت أي حاجة.

## البيانات بتتخزن فين؟

- كل السجلات بتتحفظ في `localStorage` بتاع المتصفح اللي بتفتح منه الموقع.
- يعني البيانات مرتبطة بالمتصفح والجهاز، ومش بتتنقل لوحدها لجهاز تاني.
- في وضع البيانات تقدر تصدّر نسخة احتياطية: **تصدير CSV** أو **تصدير JSON**.

## ملاحظات مهمة

- كلمات السر مكتوبة جوه `app.js` في أول سطر تقريبًا:

  ```js
  const PASSWORDS = { '123': 'notebook', '321': 'data' };
  ```

  تقدر تغيّرها من هناك، بس خلي بالك إنها حماية بسيطة مش تشفير حقيقي.
- لو مسحت بيانات المتصفح (Clear browsing data) السجلات هتتمسح، فخد تصدير نسخة احتياطية كل فترة.
- عشان تجرب من جديد: من إعدادات المتصفح امسح بيانات الموقع، أو من الـ Console:

  ```js
  localStorage.clear();
  ```

## الملفات

| الملف | وظيفته |
|-------|--------|
| `index.html` | هيكل الصفحات (شاشة الدخول، الدفتر، البيانات) |
| `styles.css` | الشكل والتنسيق والاستجابة للموبايل |
| `app.js` | المنطق: الدخول، الحفظ، البحث، التصدير |
